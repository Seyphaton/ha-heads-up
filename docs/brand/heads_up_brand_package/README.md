# Heads Up — Brand Asset Package

Brand icon: open-roof house with an outlined notification bell, no radio waves.

## Deliverables
- Six full-background variants: main, bright, dark, flat_blue, flat_white, flat_navy.
- Four transparent vector variants: on_light, on_dark, monochrome_black, monochrome_white.
- SVG vector masters and PNG exports at 16–2048 px; selected WebP exports.
- Favicon ICO and PNG files.
- Color palette as JSON, CSS custom properties and SVG swatch sheet.

## Usage
Use main for general app surfaces, bright for light-forward promotion, dark for dark mode. Use transparent on_light on light backgrounds and on_dark on dark backgrounds. Keep the house and bell proportions consistent; do not add broadcast waves.

## Production note
These are newly reconstructed vector assets based on the supplied visual reference, not pixel-identical source vectors. Colors are an indicative brand palette, not sampled specifications. Review at 16 px before shipping. No proprietary font files are included.
