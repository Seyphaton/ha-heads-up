# Heads Up

A Home Assistant custom integration and Lovelace card that show dismissible banners inside a dashboard. Automations and scripts create and clear banners through actions; the dashboard holds no message text.

Status: in development. There is no release yet. Action reference: [docs/actions.md](docs/actions.md). Card reference: [docs/card.md](docs/card.md). Examples, including REST and WebSocket calls: [docs/examples.md](docs/examples.md).
